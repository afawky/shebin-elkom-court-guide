# تحديث دليل محكمة شبين الكوم

## الجديد
- رفع صور متعددة لكل مكتب وعرضها في الدليل العام.
- تغيير شعار الموقع وصورة الواجهة الرئيسية.
- تعديل اسم الموقع والعنوان والترحيب والنص السفلي.
- تعديل الهاتف والبريد والعنوان ورابط فيسبوك.

## خطوات التحديث
1. شغّل ملف `supabase-migration-photos-settings.sql` في Supabase SQL Editor.
2. ارفع الملفات المحدثة من هذا المجلد إلى جذر مستودع GitHub مع استبدال القديمة.
3. انتظر GitHub Pages ثم حدّث الموقع بـ Ctrl+F5.

الصور عامة للعرض، لكن الرفع يتطلب حساب مدير. الحد الأقصى 5MB، والصيغ JPG/PNG/WEBP. لا تضع أبدًا sb_secret أو service_role في ملفات الموقع.
